대본이 쓴 말을 갈랐다 → [`sorting/가리기.md`](sorting/가리기.md).

| 갈래 | 개수 |
|---|---|

| ② 문제 있었음 | 24 |
| ③ 안 씀 | 90 |
| ④ 못 가린 것 | 2 |

> **★ 바로잡음 (2026-09-23 · 📮 P-61).** 위 ② 24건 가운데 `틀시안 차이`
> 빨강은 **거짓 빨강이었다.** 초안은 1280×720 으로 굽는데 검사는 1920×1080
> 계획 PNG 와 견주었다. 같은 대본을 **최종(1920×1080)으로 다시 구우니
> 빨강 0** 이다 (점검6 25/25 → 0 · 점검7 6/6 → 0).
> 새 법전 **제14조**가 바로 이것을 막는다 —
> *"견주는 두 그림은 크기가 같아야 한다. 늘리거나 줄여서 견준 결과는 증거가 아니다."*
> 어긴 쪽은 **검사기**다 (제17조 셋째 갈래). 제27조로 **무효** 처리할 건이다.
>
> 지난 판들: `표 줄` 빨강 17건도 거짓 빨강이었다 (📮 P-27 — 재는 쪽이 예전
> 길로 다시 그려서 쟀다). 1판은 검사 591줄이 `못 쟀습니다` 였다 (📮 P-25).

## 여기에 올리는 것 · 안 올리는 것 (제10조)

* 올린다 — **법전 파일과 목록뿐**
* 안 올린다 — 코드 · 열쇠 · **대본 본문** · 영상 · 까닭 · 사건 · 진행 상황

가려서** 올린다 (`회차1` … `회차9`).
