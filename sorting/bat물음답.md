## 2. `업데이트.bat` 의 주소가 왜 `-` 인가 — **고칠 것이 없습니다**

### 주소는 맞습니다

`업데이트.bat` **25줄**이 주소를 찍습니다.

```
"%PY%" -c "import sys; sys.path.insert(0,r'%HERE%'); from pipeline import program; print('  지금 프로그램: %%s' %% program.label()); print('  받을 주소: https://github.com/anords1021-sys/-/archive/refs/heads/%%s.zip' %% program.branch())" 2>nul
```

여기 적힌 `anords1021-sys/-` 는 **진짜 저장소 이름 그대로**입니다. 글자가 깨진 것이 아닙니다.

### 그럼 왜 Not Found 이 나나 — **저장소가 비공개라서**입니다

GitHub 은 **비공개 저장소를 안 들어간 사람에게 "없다(404)"** 고 답합니다.
"주소가 틀렸다"가 아니라 **"당신에게는 안 보인다"** 는 뜻입니다.

### 그러면 어떻게 받나 (셋 중 하나)

**가) 브라우저에 GitHub 로그인부터 하고 그 주소를 엽니다** — 가장 쉽습니다
1. 브라우저에서 `https://github.com` 을 열고 **로그인**합니다 (`anords1021-sys` 계정)
2. 그다음 주소창에 이것을 붙여 넣습니다:
   `https://github.com/anords1021-sys/-/archive/refs/heads/program2.zip`
3. 다운로드 폴더에 zip 이 받아집니다. 그 뒤 `업데이트.bat` 을 다시 누릅니다

**나) 저장소 화면에서 단추로 받습니다**
1. 로그인한 채로 `https://github.com/anords1021-sys/-/tree/program2` 를 엽니다
2. 초록 **`Code ▾`** 단추 → **`Download ZIP`**

**다) 저장소 이름을 읽기 쉬운 것으로 바꿉니다** (사장님이 정하실 일)
`-` 는 주소에서 헷갈리기 쉽습니다. 예: `jeogiboso-2`.
**바꾸면 `업데이트.bat` 25줄의 주소도 같이 바꿔야 합니다.**
지금은 바꾸지 않았습니다.

## 3. `점검용대본돌리기.bat` 의 `> was unexpected at this time.`

### 깨진 줄 — **11줄**입니다

```
  for /f "delims=" %%P in ('where python 2^^>nul') do set "PY=%%P"
                                            ↑↑
                                         갈매기가 둘
```

### 왜 그 오류가 나나

`cmd` 는 `^` 를 **"다음 한 글자를 글자로 봐 달라"** 는 표시로 씁니다.

* `2^>nul` — `^` 가 `>` 를 감싸므로 `>` 는 **글자**가 됩니다. **맞는 꼴**
* `2^^>nul` — 앞 `^` 가 **뒤 `^` 를 감싸** 버립니다. 그러면 `>` 는 **아무도 안 감싼 맨몸**이 되어
  `cmd` 가 **"여기로 내보내라"는 명령**으로 읽습니다. 내보낼 곳이 없으니
  **`> was unexpected at this time.`** 입니다

### 고치려면 (고치지 않았습니다)

11줄의 `2^^>nul` 을 **`2^>nul`** 로 — **갈매기 하나를 지우면** 됩니다.

### **같은 병이 여섯 파일에 있습니다** — 다 11줄입니다

| 파일 | 줄 |
|---|---|
| `끊김점검.bat` | 11 |
| `두길비교.bat` | 11 |
| `설정차이.bat` | 11 |
| `점검용대본돌리기.bat` | 11 |
| `틀판점검.bat` | 11 |
| `판조사.bat` | 11 |

**멀쩡한 파일 열 개**는 이미 `2^>nul` (갈매기 하나)로 적혀 있습니다 —
`시작.bat`(29 · 30줄) · `업데이트.bat` · `국기점검.bat` · `배경음점검.bat` ·
`블록그림.bat` · `비교판.bat` · `아이콘점검.bat` · `그래픽카드_설치.bat` ·
`setup_program2.bat` · `setup_sources.bat`.

→ **맞는 꼴이 이미 프로그램 안에 있습니다.** 여섯 개만 그 꼴로 맞추면 됩니다.

### 글자 모양은 멀쩡합니다

여섯 파일 다 **BOM 없음 · CRLF** 로 잘 저장돼 있습니다 (CLAUDE.md 5장 5번).
깨진 것은 **갈매기 하나뿐**입니다.

## 4. 여덟 편을 돌리는 정확한 한 줄

폴더 `D:\ytauto2` 에서:

```
python tools\점검돌리기.py
```

프로그램이 들고 있는 파이썬을 꼭 쓰시려면:

```
"D:\ytauto2\python\python.exe" "D:\ytauto2\tools\점검돌리기.py"
```

붙일 수 있는 것:

| 붙이는 말 | 뜻 |
|---|---|
| `--편 1,3` | 그 편만 돌린다 |
| `--초안 안함` | 영상은 안 만들고 **채점만** 한다 (빠릅니다) |

보기 — 1편과 6편만, 영상 없이:

```
python tools\점검돌리기.py --편 1,6 --초안 안함
```

결과는 작업 폴더의 **`점검결과\`** 에 한곳으로 모입니다.

## 5. 평소 켜시는 파일과 앱 안의 단추

### 평소 켜실 때 — **`시작.bat`** 이 맞습니다

`시작.bat` 은 파이썬을 찾아 **`app.py`**(프로그램 화면)를 띄웁니다 (72줄).

### **앱 안에 단추가 이미 있습니다** — bat 이 없어도 됩니다

화면에 **`점검용 대본 돌리기`** 단추가 있습니다 (`app.py` 824줄).
누르면 이렇게 물어본 뒤 돌립니다 (`app.py` 2477~2495줄):

> 점검용 대본 다섯 편(블록 142개)을 처음부터 끝까지 돌립니다.
> · 프로젝트 `점검1` ~ `점검5` 를 새로 만듭니다 (지금 작업과 섞이지 않습니다)
> · 실사를 받고 초안까지 만들어 **시간이 꽤 걸립니다**
> · 끝나면 결과 폴더를 열어 드립니다

**즉 `점검용대본돌리기.bat` 이 깨져 있어도, `시작.bat` → 그 단추로 돌릴 수 있습니다.**

### 다만 한 가지 — **글이 "다섯 편"이라고 되어 있습니다**

단추 설명도 bat 의 안내문도 **"다섯 편"** 인데, `tools/점검돌리기.py` 47~48줄은
**여덟 편**(`점검1` ~ `점검8`)을 돌립니다. **도는 것은 여덟 편이 맞습니다.**
글만 예전 그대로입니다. 고치지 않았습니다.
